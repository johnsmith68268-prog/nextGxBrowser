# nextGx Browser

A fast, customizable Chromium-based desktop browser built with Electron (`WebContentsView`), featuring:

- **Multi-Tab & Separate Private Window (`Ctrl+Shift+N`)** with a dedicated dark Private Start Page
- **Built-in Network & Cosmetic Ad/Tracker Blocker**
- **Left Floating Overlay Dock** with dropdown switcher for **YouTube Music, Spotify, Apple Music, SoundCloud, Deezer, Tidal**, plus **ChatGPT / Claude / Gemini** and **Twitch** (drag-to-resize & pinnable)
- **Site Security & Permissions Popover** (per-site Camera, Microphone, Location, Notifications controls)
- **Pro Download Manager** (live speed, ETA, Pause/Resume/Cancel, category filters)
- **Area Selection & Full-View Screenshot Capture**
- **8 GB RAM Saver** (automatic background tab hibernation + live RAM/CPU monitor)
- **Chrome-style WebUI Pages**: History (`Today/Yesterday/Older` + time-range clear), Downloads, Bookmarks, Passwords & Autofill, Extensions (`Load Unpacked`), and Settings
- **UI Sound Effects** & 4 Neon/Dark Themes (`nextGx Violet`, `Crimson`, `Cyber Cyan`, `Matrix Emerald`)

## Run Locally

```bash
npm install
npm start
```
